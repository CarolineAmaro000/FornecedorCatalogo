3. Converter pedido (unidades → caixas)

Cole o pedido, uma linha por item. Aceita SKU<TAB>QTD ou SKU - QTD. Exemplo:
ACA-SEDAN-GG-P - 105
Se o SKU não bater exatamente com o catálogo (hífen faltando, barra em vez de hífen, etc), o sistema tenta achar o mais parecido pelo "miolo" do código e avisa para você confirmar.

4. Comparar com planilha

A planilha precisa ter uma coluna de código (aceito: codigo, código, sku, referencia).
Opcional: coluna de preco/preço/valor para checar se bate, e coluna de quantidade/qtd/unidades para converter em caixas fechadas.

6. Verificar preço do catálogo x base de custo

Verifica se preço do catálogo × (1 − desconto) bate com o custo cadastrado na base. Aceita colar o link de uma planilha Google Sheets pública ("qualquer pessoa com o link pode ver") ou subir um arquivo .xlsx/.csv com colunas de código/SKU e custo.
